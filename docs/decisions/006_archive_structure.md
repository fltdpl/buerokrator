# Entscheidung 006

Dokumente werden nach Jahr und Kategorie archiviert.

## Struktur

Kategorienamen aus `config/settings.yaml` (`archive.category_mapping`):

archive/

- Jahr
	- Rechnungen (invoice)
	- Steuern (tax)
	- Versicherungen (insurance)
	- Vorsorge (pension)
	- Bank (bank)
	- Wohnen (housing)
	- Arbeit (employment)
	- Recht (legal)
	- Sonstiges (unknown)

## Begründung

Dokumente sollen dort abgelegt werden,
wo sie später gesucht werden.
